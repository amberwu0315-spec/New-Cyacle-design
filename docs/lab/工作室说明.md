# Lab 工作室说明

> 这里是**设计探索场**，不是产品代码。产出是判断和证据，代码可以丢。

## 它是什么

`app/src/web.lab` 是同一仓库、同一个 app 里的**第二个 Web 入口**：

- 同一个 Go server（`127.0.0.1:7088`）、同一份数据、同一个登录态；
- 与正式版并排：正式版在 `/`，lab 在 `/lab`；
- 有自己的 `package.json`、vite、router、壳，改壳不影响正式版；
- 不在 `build.yaml` 里，正式构建产物里没有它。

## 三条命令

```bash
# 1. 起（server + 正式版 + lab 一起）
bash app/src/web.lab/scripts/dev.sh
#    只起 lab 前端：plot art dev web.lab

# 2. 看（三档宽度截图 → docs/lab/evidence/）
node app/src/web.lab/scripts/shot.mjs --path /project/projects --name projects

# 3. 回（把壳恢复到 parity 基线）
bash app/src/web.lab/scripts/reset.sh
```

打开：`http://127.0.0.1:7088/lab`

## 变体开关

同一个页面切换不同壳层方案，用 `?v=`，不用开分支：

```
/lab/project/projects            → baseline（和正式版一致）
/lab/project/projects?v=v2-flat  → 你注册的第二个方案
```

右下角会出现一个悬浮切换器，列出所有已注册变体。

**新增一个方案：**

1. 复制 `src/shell/baseline-layout.tsx` 指向的实现（即 `src/components/layouts/app-layout/`）为
   `src/shell/v2-flat-layout.tsx`，在里面改结构；
2. 在 `src/shell/variants.ts` 注册：`'v2-flat': V2FlatLayout`；
3. 浏览器 `?v=v2-flat` 立刻可见。

约束：每个变体都是"自带 `<Outlet />` 的完整壳"，别在变体里再套别家的壳。

## 目录

```
app/src/web.lab/
├─ src/
│  ├─ components/layouts/    parity 抄来的壳（app-layout / admin-layout）
│  ├─ shell/                 变体注册表、切换器、基线
│  ├─ shell/baseline-layout.tsx  ← 指向 parity 壳，不要改它
│  ├─ features/ pages/       app 级页面（首页、404、错误页）
│  ├─ lab-modules.ts         domain 清单（用脚本同步，别手改）
│  └─ generated/             plot 生成，勿手改
├─ scripts/
│  ├─ dev.sh                 起应用（顺带清理僵尸运行标记）
│  ├─ shot.mjs               三档截图
│  ├─ reset.sh               回到 parity
│  └─ sync-modules.mjs       同步 domain 清单
```

- `/lab` 经 7088 返回 200；
- 未登录时渲染出真实的 uic 登录页（见 `docs/lab/evidence/lab-boot-1280.png`），说明 domain 路由、样式链路都已接通；

- `plot app apply` 不会覆盖 `src/` 下已存在的文件，可以放心改。

未验证：

- 登录后的壳层渲染。截图脚本的 profile 里没有会话，需要先 `node app/src/web.lab/scripts/shot.mjs --login` 手动登录一次。

## 规则

1. **不动 `app/src/web`、不动 `domain/base`、不动 server。** 要改就是提案，回主仓排期。
2. **不改 `src/components/layouts/`**（那是 parity 锚点）。要改壳就复制成新变体。
3. **不改 `src/generated/` 和 `lab-modules.ts`**：前者 plot 生成，后者跑 `sync-modules.mjs`。
4. 每个实验在 `docs/lab/<编号>-<主题>/` 留一份 README：假设、2 个以上方案、三档截图、反事实证明、结论。

## 已知坑

- **`/bin/ps` 被沙箱禁用**，被强杀后 plot 会留下 `instance.json` 挡住下次启动。`dev.sh` 已经帮你清理；手动起服务前先确认 7088 空闲。
- **headless 截图不能用 `--screenshot`**：登录页有持续请求，load 事件不触发。`shot.mjs` 走 CDP，等固定毫秒后抓帧（可用 `--settle` 调）。
- **lab 的 domain 清单不会自动更新**：main 新增 domain 后跑 `node app/src/web.lab/scripts/sync-modules.mjs`，否则新页面在 `/lab` 下 404。
