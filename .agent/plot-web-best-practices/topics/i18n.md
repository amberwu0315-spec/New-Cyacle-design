# Plot Web i18n 推荐模式


## 何时使用

项目已经接入多语言能力。只要修改或新增用户可见文案，就必须读取本参考并遵循项目现有的 i18n 风格：复用已有的 store、catalog、locale 命名、消息 key 和插值协议，不得直接写死文案或另起一套实现。只有在确实尚未接入 i18n 的项目中，才按用户是否明确要求多语言、语言切换、locale 文案或 i18n 维护决定是否引入；不要因新建页面而脱离项目约定另行实现。

```text
项目已有 i18n（默认） → 先查现有实现，延续 store、catalog、locale 命名、消息 key 和插值协议
项目没有 i18n + 用户明确需要 → 推荐采用本模式
项目没有 i18n + 用户未要求   → 不引入
```

以下均为**项目参考模板**。存储介质、默认语言和支持语言应按产品要求调整。

## 推荐结构

共享语言状态和 catalog 工厂放 Base；每个 domain 只维护自己的消息与 catalog。

```text
domain/base/src/<artifact>/src/lib/i18n/
├── language-store.ts
├── i18n-factory.ts
└── index.ts

domain/<name>/src/<artifact>/src/lib/i18n/
├── i18n-catalog.ts
├── index.ts
└── messages/
    ├── zh-CN/
    │   ├── common.ts
    │   ├── home.ts
    │   └── index.ts
    └── en-US/
        ├── common.ts
        ├── home.ts
        └── index.ts
```

## 项目参考模板：单例 Language Store

```ts
// domain/base/src/<artifact>/src/lib/i18n/language-store.ts
import * as React from "react"

export const SUPPORTED_LANGUAGES = ["zh-CN", "en-US"] as const
export type SupportedLanguage = (typeof SUPPORTED_LANGUAGES)[number]

const DEFAULT_LANGUAGE: SupportedLanguage = "zh-CN"
const STORAGE_KEY = "language"
const listeners = new Set<() => void>()

function normalizeLanguage(value: string | null): SupportedLanguage {
  return value === "en-US" || value === "zh-CN" ? value : DEFAULT_LANGUAGE
}

function readStoredLanguage(): SupportedLanguage {
  if (typeof window === "undefined") return DEFAULT_LANGUAGE
  try {
    return normalizeLanguage(window.localStorage.getItem(STORAGE_KEY))
  } catch {
    return DEFAULT_LANGUAGE
  }
}

function persistLanguage(language: SupportedLanguage) {
  if (typeof window === "undefined") return
  try {
    window.localStorage.setItem(STORAGE_KEY, language)
  } catch {
    // 存储不可用时仍保留当前页面内的语言切换。
  }
}

function applyDocumentLanguage(language: SupportedLanguage) {
  if (typeof document !== "undefined") {
    document.documentElement.lang = language
  }
}

let currentLanguage = readStoredLanguage()
applyDocumentLanguage(currentLanguage)

function emit() {
  listeners.forEach((listener) => listener())
}

export const languageStore = {
  getSnapshot: () => currentLanguage,
  getServerSnapshot: () => DEFAULT_LANGUAGE,
  subscribe: (listener: () => void) => {
    listeners.add(listener)
    return () => listeners.delete(listener)
  },
  setLanguage: (language: SupportedLanguage) => {
    if (language === currentLanguage) return
    currentLanguage = language
    persistLanguage(language)
    applyDocumentLanguage(language)
    emit()
  },
}

export function useLanguageStore() {
  return React.useSyncExternalStore(
    languageStore.subscribe,
    languageStore.getSnapshot,
    languageStore.getServerSnapshot,
  )
}
```

`localStorage` 只是默认示例。项目要求跨子域、SSR 或服务端协商时可以改为 cookie，但继续保持单例 `getSnapshot/subscribe/setLanguage` 边界。

## 项目参考模板：Catalog 工厂

```ts
// domain/base/src/<artifact>/src/lib/i18n/i18n-factory.ts
import * as React from "react"

import type { SupportedLanguage } from "./language-store.ts"
import { languageStore, useLanguageStore } from "./language-store.ts"

export function createI18nCatalog<TMessages>(
  messages: Readonly<Record<SupportedLanguage, TMessages>>,
) {
  const getMessages = (
    language: SupportedLanguage = languageStore.getSnapshot(),
  ) => messages[language]

  const useTranslation = () => {
    const language = useLanguageStore()
    const t = getMessages(language)

    return React.useMemo(() => ({ language, t }), [language, t])
  }

  return { getMessages, useTranslation }
}
```

```ts
// domain/base/src/<artifact>/src/lib/i18n/index.ts
export { createI18nCatalog } from "./i18n-factory.ts"
export {
  languageStore,
  SUPPORTED_LANGUAGES,
  useLanguageStore,
} from "./language-store.ts"
export type { SupportedLanguage } from "./language-store.ts"
```

## 项目参考模板：Typed Messages

普通文案使用字符串，带参数文案使用 typed function。不要在新模式中额外引入 `{param}` 字符串 formatter。

```ts
// messages/zh-CN/home.ts
export const home = {
  title: "首页",
  empty: "暂无数据",
  count: (count: number) => `共 ${count} 项`,
}
```

```ts
// messages/zh-CN/index.ts
import { home } from "./home.ts"

export const zhCN = { home }
export type Messages = typeof zhCN
```

```ts
// messages/en-US/home.ts
import type { home as ZhCNHome } from "../zh-CN/home.ts"

export const home = {
  title: "Home",
  empty: "No data",
  count: (count: number) => `${count} items`,
} satisfies typeof ZhCNHome
```

```ts
// messages/en-US/index.ts
import type { Messages } from "../zh-CN/index.ts"
import { home } from "./home.ts"

export const enUS = { home } satisfies Messages
```

不要给默认语言消息对象添加 `as const` 后再用 `satisfies typeof DefaultMessages` 校验其它语言；这会把中文字符串收窄为字面量，导致英文文案无法通过类型检查。

App 需要本地化 title/description 时增加独立 `metadata.ts`，供 RootShell 使用：

```ts
// messages/zh-CN/metadata.ts
export const metadata = {
  title: "应用工作台",
  description: "应用工作台描述。",
}

// messages/en-US/metadata.ts
import type { metadata as ZhCNMetadata } from "../zh-CN/metadata.ts"

export const metadata = {
  title: "Application Workspace",
  description: "Application workspace description.",
} satisfies typeof ZhCNMetadata
```

把 `metadata` 合并进 app locale 的 `index.ts`；RootShell 模式见 [routing-and-layout.md](routing-and-layout.md#root-metadata-与-rooterror)。

## 项目参考模板：Domain Catalog

```ts
// src/lib/i18n/i18n-catalog.ts
import { createI18nCatalog } from "@scope/web-base"

import { enUS } from "./messages/en-US/index.ts"
import type { Messages } from "./messages/zh-CN/index.ts"
import { zhCN } from "./messages/zh-CN/index.ts"

export const i18nCatalog = createI18nCatalog<Messages>({
  "zh-CN": zhCN,
  "en-US": enUS,
})

export const getMessages = i18nCatalog.getMessages
export const useTranslation = i18nCatalog.useTranslation
```

```ts
// src/lib/i18n/index.ts
export { getMessages, i18nCatalog, useTranslation } from "./i18n-catalog.ts"
export type { Messages } from "./messages/zh-CN/index.ts"
```

## 使用

React 组件通过 hook 读取当前语言：

```tsx
export function HomePage() {
  const { t } = useTranslation()
  return <p>{t.home.count(12)}</p>
}
```

Nav factory、route metadata 等非 React 场景显式传入语言，不调用 hook：

```ts
export function createHomeNav(language: SupportedLanguage) {
  const t = getMessages(language)
  return { label: t.home.title, to: "/home" }
}
```

跨 domain 暴露 i18n 能力时通过该 domain 的 `./pub`，在消费处 alias；不深链 message 文件。

## DO / NOT

| DO | NOT |
| --- | --- |
| 用户需要时才引入 i18n | 把 i18n 当作每个 Plot 页面必选能力 |
| 所有 domain 共享 Base 单例 store | 每个 feature 创建自己的语言 state/store |
| 默认语言提供消息结构类型 | 不同 locale 各自维护无关联对象 |
| 参数文案使用 typed function | 新项目混入第二套字符串 formatter |
| React 用 `useTranslation()` | 普通函数或 route factory 调 React hook |
| 切换语言同步 `<html lang>` | 只替换文本而不更新文档语言 |
| 存储不可用时安全回退 | 让 localStorage/cookie 异常阻断渲染 |
